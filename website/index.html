What you get

A real client, not a status screen

Everything below works the same on the desktop app, in a browser, and on the iPhone app.

Readable transcripts

Diffs inline, tool calls collapsed, live command output as it streams. Not a terminal you have to squint at.

Approve from anywhere

When an agent asks to run something, you get a button: on whichever device you happen to be holding.

Notifications that find you

Desktop while you are at the machine, phone push once you walk away. Never both, never for something you are watching.

Real tmux underneath

Every session is a genuine tmux window. SSH in alongside Manta whenever you want; it is the same box.

Parallel worktrees

Delegate long jobs to background agents, each in its own git worktree and branch. They never touch your checkout.

Search every session

One query across the full history of every conversation on the box, whichever agent produced it.

Voice, files and screenshots

Dictate a prompt, drag a file onto a session, paste a screenshot. It lands on the server, not in a cloud bucket.

Scheduled and triggered work

Run a prompt on a cron, or let CI wake a session by webhook. Work that starts without you being there.

Secrets stay secret

Hand an agent a token by reference, never by value. It uses the credential without it entering the transcript.

FAQ

Questions people actually ask

Can I use my existing Claude and Codex subscriptions?

Yes. You log each agent CLI into your own plan once on the server, and Manta runs them side by side. No Manta account, no proxy, no per-seat fee.

How long does setup actually take?

About two minutes. Point the desktop app at a server and it installs the runtime, starts the service, gets a certificate and shows a six-digit pairing code for your other devices.

Does the agent keep running if I close my laptop?

Yes. Agents live in tmux sessions on the box as system services. Clients are disposable; close them all and the work continues, with full history when you reconnect.

What kind of server do I need?

Any always-on Linux box or Apple Silicon Mac. A five dollar VPS is enough. The installer touches no system packages and brings its own runtime.

Does my code leave my box?

No. Transcripts, uploads, secrets and config stay on the machine. The only outbound traffic is your agent talking to its own provider.

Do I need Tailscale, a VPN or port forwarding?

No. If Tailscale is already running, devices connect over your tailnet. If not, the box gets its own hostname and certificate. Either way, nothing to port-forward.

Is Manta really open source?

Yes: MIT licensed, client and server both. Read every line, build it yourself, run it with no connection to us. No account, no hosted tier. Telemetry is optional and sends nothing unless you set a token.

Is this an alternative to Conductor or Orca?

They overlap on a different bet. Those run agents on your Mac; Manta runs them on a server you own and gives every device the same window onto the work.
