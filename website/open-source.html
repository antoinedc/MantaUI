Licence

MIT, with a working install script you can read

Open source in this product is not a marketing line. The repo carries a working MIT licence, the install script is in the repository, and every line of the server, the desktop app and the phone client is on GitHub.

  • ✓MIT licensed. Permissive, friction-free, matches Orca. Fork it, run your own gateway, write your own client, ship a derivative.
  • ✓The install script is in the repo. Read install.sh before you pipe it into bash. It is roughly two hundred lines of plain bash, with a checksum-verified download.
  • ✓The server is open source. Express, the tmux and opencode proxies, push, schedules, webhooks, secrets, peer sessions. Every line.
  • ✓The desktop app is open source. Electron, xterm.js, React. The renderer is a normal npm package. Build it from source if you prefer.
  • ✓The phone app is open source. Capacitor shell around the same React client. The native bits are minimal glue.
Self-hosted

No account, no telemetry, no seat count

The product runs on hardware you own. There is no hosted control plane to sign up for, no usage telemetry leaving the box, and no seat count to grow into a bill.

  • ✓Nothing to sign up for. Pairing is a six-digit code your box generates. Devices exchange tokens, and that is the only credential in the loop.
  • ✓No telemetry. The box talks to your model provider and to APNs for push fanout. Nothing else. The repo carries no analytics SDK.
  • ✓Your code stays on your box. Transcripts, uploads, secrets and configuration live on your machine. The only outbound traffic is your agent talking to its model provider.
  • ✓No hosted control plane. There is no workspace limit, no seat count, no Pro tier. The product is one binary plus a directory of state.
  • ✓You can fork the box. Want a different default model, a different push provider, a different default port. Fork the repo, edit the manifest, run the install.
Auditability

The install is auditable end to end

The single sharpest difference between an open source product and a "self-hosted" one is whether the install can be read before it runs. Manta's can.

  • ✓Source on GitHub. Every commit, every change, every reviewer. The repo is the source of truth for what ships.
  • ✓Checksum-verified download. The manifest on the website lists a sha256 for each tarball. The script refuses to run if the bytes do not match.
  • ✓No silent install of unrelated packages. The privileged section installs Caddy and registers a hostname. Both are visible, both are reversible, both leave a trail.
  • ✓Reproducible from the manifest. A clean box, the manifest, and a known tarball reproduce the same install every time.
FAQ

Questions about the licence and the install

Five questions, answered in full.

Where is the source code?

On GitHub at github.com/antoinedc/MantaUI. The server, the Electron desktop app, the React renderer, the phone client and the install script all live in the same repository.

What is the licence?

MIT. The full text is in the LICENSE file at the root of the repository. It is permissive: fork it, modify it, ship a derivative, keep the copyright notice.

What stays on my box?

Everything. Transcripts, uploads, secrets, configuration, schedules, peer metadata, ingress choice. The only outbound traffic is your agent talking to its model provider, and a small push payload carrying the session name when you turn on phone notifications.

Can I run my own gateway or push provider?

Yes. Fork the repo, point the push routing at your own gateway, edit the manifest. The push and webhook modules are designed to be replaced. The same goes for the install script, the installer, and the desktop app.

Does the box phone home?

Only to your model provider and to APNs, when you have phone notifications turned on. There is no analytics SDK, no telemetry beacon, no usage ping. The pricing page covers what you actually pay for.

Put it on your own box

Free, open source, MIT. Runs on a Linux VPS or a Mac you already own.

$ curl -fsSL https://mantaui.com/install.sh | bash
