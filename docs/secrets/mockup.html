Secrets — editing everywhere

Two changes: (A) every row in the chat's 🔑 popover becomes editable in place — rename, replace the value, change the hint; (B) a new Settings → Secrets page lists every secret on the box, grouped Shared / Projects / Sessions, with the same inline editor.

Invariant unchanged: a stored value is never sent back to any screen. "Editing the value" means replacing it — the field shows dots and a "Replace" button, never the old value.
