Decisions shown in this mockup

  • One sidebar row, never one per run. “Routines” sits under CTO. A red count means runs that need you; a blue count means unread findings.
  • Every run is a fresh session that lives on the Routines page. Opening one shows the normal transcript with a header saying which routine and run it is. Replying keeps it on the Routines page. Keep in sidebar turns it into a normal session.
  • Memory is always on and always visible. It isn't a setting. Each routine has one “What it remembers” note that every run reads first and updates at the end. Changes are highlighted, you can edit it, and the transcript shows the read and update steps.
  • A run ends with a report. “Findings” is unread and notifies you if the routine is set to. “Nothing new” is filed quietly and already marked read. “Failed” and “Needs you” always notify.
  • Routines have their own queue, and runs are never dropped. Two run at once. The rest wait in order and show their place in line. A routine that's already waiting isn't queued twice. Runs missed while the box was off run once when it comes back, up to 6 hours late. The history notes when a run waited or caught up.
  • The old per-chat scheduler becomes part of Routines. One store and one engine with two destinations: “new session each run” (a routine) or “inside this chat” (a follow-up). Follow-ups are listed at the bottom of the Routines page. The composer's clock button still shows the current chat's follow-ups. The AI uses the same tool for both and picks the destination, as it does in ChatGPT and z.ai.
  • A job can move either way. Since both kinds live in one store, moving is just changing where it posts. Follow-up → routine: the instructions are rewritten to stand alone and what the chat knew becomes the routine's memory. Routine → chat: the memory is posted into the chat once and then the chat is the context, while the note is kept as it was so you can move it back. Nothing already delivered moves: past runs stay where they were.
  • Three ways to create one: the form, asking in any chat, or “turn this chat into a routine”. Created from a chat, it starts with the baselines from that conversation already in its memory.
