Spec notes

  • Loudest element is the file content. Chrome bars are --panel, content is --canvas, so the document reads as a page on the same surface as the transcript.
  • Alignment. The Explorer top bar is exactly the session header's height (44px), so both bottom borders form one line across the window.
  • What grows. Dragging the divider moves width between transcript and Explorer only; the sidebar and tree keep their widths. ⌘B gives the sidebar's width to both panes in their current proportion. Opening the tree takes width from the viewer only.
  • Breadcrumb truncates from the LEFT so the file name always stays visible.
  • The Rendered / Source control is shown only for Markdown; for other files its slot collapses (no gap is left).
  • The rail is not empty decoration: its status dot follows the session (working / needs you / idle) so a question is never hidden behind the expanded file.
  • Light theme uses the same tokens; nothing in this file has a per-theme override.
