Spec notes — the parts a screenshot cannot express. Two numbers govern the transcript. Every sibling block inside one turn — paragraph, tool card, diff, todo list, permission card, question card — is separated by --block-gap (12px). Turns are separated by --turn-gap (24px), which is double. The gap comes from one gap on the turn container, never from per-child margins, so a new block type inherits the rhythm and cannot opt out. Today three components each pick their own value (4 / 8 / 8 / 12px) and the hierarchy is inverted: the gap between turns is larger than the gap between a paragraph and the tool card it introduces, which is why the transcript reads as one undifferentiated column. The transcript runs the panel's full width — 28px inset from each edge, no measure cap, no centring (owner decision, BET-646). Ask cards sit at that same full width, edge-aligned with the prose — they are blocks in the conversation, not floating overlays. The composer stack below keeps the --measure (72ch) cap, so on a wide window the centred composer's left edge no longer meets the transcript's — that is intended. The header owns session state; the composer owns composing. Context %, branch and the session menu (⋯) belong in the header. Model ▸ effort, attach, voice, send, the bypass-permissions toggle and the three resource buttons stay by the input, because they change what happens when you press Enter. The sidebar row is one line and four fixed slots — [dot] [name] [pin] [timer]. The pin slot is permanently 18px wide whether or not a glyph is in it, so nothing shifts on hover; the timer has a min-width and tabular figures so 4m → 12m does not nudge it either. One dot carries every state: no trailing badge, no second status glyph, no branch or model subtitle. Emphasis: the loudest element on the screen is the primary action of whatever is blocking — the filled Allow once when a permission card is open. Reject is pushed to the far right and tinted only on hover, so the destructive option is reachable but never where the eye lands first. What grows: the transcript grows vertically within the panel's full width; the composer grows downward from a fixed top edge, so the send control never moves. Icons are stroked, never emoji — emoji render differently per platform and cannot take currentColor, which is why today's toolbar cannot be themed.
